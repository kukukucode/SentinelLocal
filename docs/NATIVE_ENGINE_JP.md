# Rustエンジンと性能改善（開発版）

Windows x64 / Windows PowerShell 5.1専用です。Windows操作・Defender連携・タスク管理はPowerShellに残し、JSONLの検証・抽出と状態管理をRustのDLLへ移しています。C#はDLL呼び出しの小さなABI接続に使います。新しい常駐サービス・通信は追加しません。

公開済みpreview.1、および2026-11-06に30/30件を保存した実測構成`f80d2f3`とは別の変更です。実機の速度改善率や防御性能は未測定です。

## 実装範囲

| 対象 | 変更と制限 |
| --- | --- |
| 試行の照合 | PID辞書を一度作り、候補だけ実行パス・SHA・生成時刻・引数を比較。PID再利用・曖昧性の拒否を維持 |
| JSONL | バッファ付き逐次読み取りで生bytesのSHA・チェーン・件数・必要行・時刻範囲を同時に計算。全履歴のオブジェクト展開を回避 |
| 検証の再利用 | SHAとログ種類・抽出条件に結びついた結果を共有。再利用前にも実bytesを再hashし、mtime・サイズだけでは信頼しない |
| 時刻索引 | 関連記録の時刻の最小・最大を検証時に取得。同じSHAの範囲外ファイルを再解析しない。不明な時刻範囲は除外に使わない |
| 相関キャッシュ | GUID辞書＋期限順最小ヒープ＋世代番号。更新O(log C)、期限切れ項目だけ除去。1000件上限。開始時に永続記録から再構築 |
| 署名キャッシュ | 辞書＋世代付きLRU。平均・償却O(1)の更新と追い出し、256件上限。既存の15秒期限は延長しない |
| 応答スケジューラ | High/Normalの準備済みヒープ＋再試行時刻ヒープ。古いNormalの優先・遅延再試行・時計巻き戻りを維持 |
| 解析キュー | 内容SHAに結びつく解析済みメタデータと進捗sidecarの照合、集計の差分更新。毎回のbytes検証は維持 |
| ファイル容量 | ファイル一覧と長さの差分から合計を更新。ファイル列挙・メタデータ照合は残るため全体O(1)ではない |
| 重複抑制 | 順序・チェックサム付き追記WALで毎回の全件JSON書き換えを回避。128更新または1MiBでスナップショット化 |

ヒープの古い世代は一定割合を超えると再構築します。対象削除・内容変更・再起動を照合します。キュー列挙やbytes検証を省略していないため、照合の入出力はキュー量に比例します。

## 安全性と復旧

DLL・ビルドメタデータ・依存ライセンス通知はパッケージ必須ファイルです。独立Bootstrapで検証して保護stagingへ入れ、整合性baselineにも登録します。DLL読込前に実bytesのSHAをメタデータと導入済みbaselineに照合します。信頼検証・DLL読込の失敗は起動失敗として扱います。

浮動小数点・深いJSON・非ASCIIプロパティ名など、RustだけでPowerShell 5.1の正規化互換性を保証できない行は既存PowerShell正規化で検証します。チェーン不一致・reparse pointは拒否します。ABI入力・出力は各16MiB、1ログ行16MiB、抽出と互換行は合計8MiBです。表現・サイズ制限を超えたログは既存の完全検証へ戻し、切り捨てません。検証キャッシュは256件かつ保持行の生データ換算16MiBを上限にします。解析キューの照合は10000件・256MiB上限を超えると未検証として失敗します。

WALは重複抑制の復旧用で、監査ログの代わりではありません。追記とflush後に記憶上の状態を更新します。集約途中の停止はスナップショットとWALを再適用し、未完了の末尾行・順序不一致・外部writerを拒否します。復旧・追記に失敗したらHIGH記録を残して永続重複抑制を停止し、元データを保持します。再起動後の重複検査を許容し、解析キューの未処理イベントは消しません。

## ビルドと試験

Rust 1.90.0、x64 Windows向けC++ビルドツールとSDKを用意します。CIは`x86_64-pc-windows-msvc`を使います。依存バージョンはCargo.lockで固定します。リポジトリのルートで実行します。

```powershell
rustup toolchain install 1.90.0 --profile minimal
rustup default 1.90.0
cargo test --locked --manifest-path native/Cargo.toml
.\tools\native\Build-SentinelEngine.ps1
.\tests\Run-NativeEngineTests.ps1
.\scripts\SelfTest-SentinelLocal.ps1 -Root . -PreStart
.\scripts\New-SentinelPackage.ps1 -OutputDirectory ..\SentinelLocal-package
```

出力は`native/bin`に作り、Gitへ登録しません。配布作成時にDLL・メタデータ・通知をflat packageへ入れます。ビルドメタデータは署名の代わりではありません。ビルド時の`-SigningCertificateThumbprint`に既存のコード署名証明書を指定するとDLLとCLIのAuthenticode署名を検証してからメタデータを生成します。パッケージのCMS署名は配布作成時に別途行います。

このPCでは新規Rustビルドの一部がWindowsのアプリ制御に拒否されました。保護設定・除外は変更せず、実行試験は隔離されたWindows CIで行います。実機導入はOSの信頼ポリシーに適合した署名済みビルドを用意してから行い、Bootstrapも変更を含む版を独立にレビューしてください。既存版のBootstrap hashを流用しないでください。

Windows 2022/2025のCIでネイティブ単体試験、PowerShell 5.1との互換試験、既存の導入・更新・セキュリティ回帰試験を行います。合成3000行JSONLの旧実装とRustの時間をCI成果物に記録します。ファイル検証の比較であり、実機測定全体やマルウェア検知速度の改善率とは区別します。
